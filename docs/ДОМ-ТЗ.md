# «Дом» — MVP (обсуждено 18.11)

Идея: у купленной недвижимости появляется кнопка «Мой дом» — открывается интерьер,
поверх которого игрок вешает свои NFT, красивые номера кошельков и статистику.

## Что делаем в первой версии

- **Одна картинка интерьера** на объект. Без комнат, без 3D, без свободного перемещения.
- **6 слотов** поверх картинки (позиции фиксированные, задаются в CSS):
  1. большая рама по центру
  2. рама слева
  3. рама справа
  4. полка (мелкие предметы)
  5. зеркало/табличка (номер кошелька)
  6. тумба (подарки/трофеи)
- **Типы содержимого слота:**
  - `nft` — картинка NFT из коллекции игрока
  - `number` — купленный элитный номер (маска вида `77****77`)
  - `stat` — только чтение: свободный KNT, стоимость портфеля, стейкинг, место в рейтинге
  - `gift` — подарок/трофей из кейса (если лежит в инвентаре)
- **Аватар не делаем.** Обсуждаем отдельно, когда захочет.

## Как игрок попадает внутрь

- В «Моё имущество» и в модалке предмета (`dxAssetOpen`) — кнопка «🏠 Мой дом».
- Кнопка видна только если объект куплен (`ext.assets` содержит id).
- Открывается на весь экран: картинка интерьера + полупрозрачная панель слотов.
- Клик по слоту → список того, что можно повесить (без перетаскивания мышкой — иначе утонем).
- Закрыть: крестик или Esc. Кнопка «убрать» у каждого слота.

## Данные

Живёт внутри `ext` (ключ `de_ext_v1`), то есть синкается тем же механизмом, что имущество — новые запросы к серверу не нужны.

```js
ext.house = {
  "penthouse_ny": {
    slots: [
      { i: 1, kind: "nft",    ref: "nft_0042" },
      { i: 2, kind: "number", ref: "77777777" },
      { i: 5, kind: "stat",   ref: "knt" },
      { i: 6, kind: "gift",   ref: "eternal_flame" }
    ]
  }
}
```

Правила:
- один предмет — один слот, повторно не ставится;
- если NFT продан/передан — слот очищается при следующем открытии;
- слот без данных рисуется как пустой (пунктирная рамка + «повесить»);
- удаление объекта из имущества чистит его `house`-запись.

## Картинки интерьеров

- Пул уже есть: 9 разных интерьеров в `assets/img` (`int1…int9`).
- Для MVP привязка: тип объекта → картинка (`flat`→int1, `house`→int2, `villa`→int3, `penthouse`→int4, `castle`→int5).
- Позже: свой интерьер на каждый объект + смена по `inside` (стиль из данных объекта).

## Этапы

1. Каркас: кнопка, экран, 6 слотов, сохранение в `ext.house`.
2. Наполнение: NFT, номера, статистика, подарки.
3. Красивости: разные интерьеры по типам, анимация появления.
4. (Позже) аватар и комнаты.

## Чего в MVP нет

- комнат и переключения между ними;
- свободного размещения (drag&drop) — только выбор из списка;
- 3D, прогулок, гостей.
