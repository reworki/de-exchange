# ТЗ 3.0: живые боты на бирже

Статус: в работе (19.11.2026) · база: DE v2.9 · API: Netlify Functions + Blobs

## 1. Задача

В игре нет реальных людей, кроме владельца. Нужно, чтобы биржа выглядела и жила как настоящая:
**50 ботов** с собственными аккаунтами и балансами, которые **сами развиваются по-разному** —
кто-то остаётся бедным, кто-то вырастает в миллиардера и со временем обгоняет человека.

Не скрипт «через месяц все миллиардеры», а экономика: характеры, риск, везение, траты,
сделки, переводы друг другу, смена био и аватарок. Человек продолжает играть на равных.

## 2. Боты — обычные аккаунты

Отдельной сущности нет: бот — это запись в том же `accounts` с флагом `bot: true`.

```js
{ nick, nick_lc, pass, wallet, bot: true,
  persona: { risk, skill, patience, luck, spend, social, ambition, activity, salaryTier, index },
  bio, avatar, created, updated, last_seen,
  social: { followers, following }, privacy: {...},
  state: { ex, nft, ext: null, led: null } }
```

Следствия: боты видны в топе, ленте, профилях и подписках; их капитал считается тем же
`/api/top`; отдельной витрины не нужно.

## 3. Характер (persona)

Детерминирован по индексу, не меняется от тика к тику:

| Поле | Смысл |
|---|---|
| `risk` | доля капитала в сделке |
| `skill` | сдвиг вероятности прибыльной сделки (0.5 — монетка) |
| `patience` | держит активы вместо быстрой продажи |
| `luck` | множитель на хорошие исходы |
| `spend` | сколько тратит на «жизнь» |
| `social` | щедрость, частота переводов другим |
| `ambition` | лезет в KNT и крупные активы |
| `activity` | вероятность быть активным в тике |
| `salaryTier` | 0..3 — доход: бомж → рантье |

## 4. Тик

- Расписание: `*/20 * * * *` (раз в 20 минут), Netlify scheduled function `bots-tick`.
- **Один тик = один игровой день.**
- За тик бот: получает доход и дивиденды, тратит на жизнь, делает 1–2 сделки,
  с малой вероятностью переводит другому боту, меняет био/аватар, изредка покупает NFT.
- Всё считается в `bot-brain.js` (чистая логика), запись — в `bots-tick.js` (один read, один write).
- Блокировка `bots_lock`: повторный запуск раньше 4 минут пропускается.
- Догоняющих циклов нет: после простоя выполняется один тик.

## 5. Экономика (без потолка)

- Рост мультипликативный с тяжёлым хвостом: большинство топчется, единицы компаундят.
- Ориентиры (проверены симулятором на 5 сидах): 60 тиков — медиана ×1.2–1.7, топ до ×600;
  3000 тиков — максимум 5.8e16…1.2e17, ботов богаче капитала владельца (2e15) — 5–7 из 50,
  19 из 50 остаются ниже 100k.
- Насыщение без капа: `sat = 1 / (1 + sqrt(cap / 3.1e15))` на дрейф, шум и лог пампа;
  с того же порога налог на роскошь 0.40–0.65%/день.
- Жёстких капов нет. Тормоза для богатых естественные: траты на роскошь 0.05–0.3%/день,
  налог 0.02–0.05%/день свыше 1e9, крупные проигрыши бьют по большим позициям.
- Сделки: p(win) = 0.42 + 0.30·skill, амплитуда ±1–9% в день, редкие джекпоты и обвалы.
- `trades` у бота — не больше 60 записей (размер Blobs).
- Никаких `NaN`, `Infinity`, отрицательных `amounts`.

## 6. Соцсеть ботов

- Переводы другим ботам (по плану из `brain`, исполняет рантайм атомарно).
- Смена био (12–20 живых фраз) и аватарки с малой вероятностью.
- События уходят в общую ленту через `pushEvent`, не больше 6 за тик.
- Подписки между ботами — по желанию, отдельным шагом.

## 7. API

| Метод | Что делает |
|---|---|
| `POST /api/bots/seed` | создать 50 ботов (идемпотентно) |
| `POST /api/bots/tick` | выполнить тик вручную (тот же код, что крон) |
| `GET /api/bots/stats` | мета + список ботов с капиталом |

Доступ: `body.key === process.env.BOTS_KEY` **или** админский аккаунт.

## 9. Риски

| Риск | Что делаем |
|---|---|
| Гонка с сохранением человека (оба пишут весь `accounts`) | тик читает и пишет в одном проходе, окно — миллисекунды; при росте нагрузки перейти на per-account ключи |
| Разрастание Blobs | `trades` 60, лента обрезается, NFT у ботов максимум 3 |
| Тик не выполнился (сайт без визитов) | Netlify cron работает независимо от визитов |
| Все боты одинаковые | детерминированные характеры + шум на тик |

## 10. Критерии приёмки

1. `/api/bots/seed` создаёт ровно 50 аккаунтов с `bot: true`, без дублей при повторном вызове. ✅ 50 создано
2. Тик меняет балансы, но не трогает аккаунты людей. ✅ проверено
3. Через 100 тиков видно расслоение: есть бедные и есть богатые, медиана выросла умеренно.
4. На длинном прогоне (симулятор, 3000 тиков) максимум 5.8e16…1.2e17, 5–7 ботов обгоняют владельца. ✅
5. Лента получает события ботов, не больше 6 за тик. ✅
6. Человек может торговать, переводить, менять профиль — боты этому не мешают. ✅
