# Деплой DE Exchange — где что лежит

## Токен Netlify (чтобы больше не терять)

| где | что |
|---|---|
| `C:\KNOT\SITE\_tools\netlify\.token` | сам токен `nfp_...` (40 символов, только токен, UTF-8 без BOM) |
| переменная окружения пользователя `NETLIFY_AUTH_TOKEN` | та же копия, действует на новые процессы |
| `%APPDATA%\netlify\Config\config.json` | профиль CLI (логин `knote6037`) |

Проверка, что токен жив: `netlify status` в `C:\KNOT\SITE` → должен показать `Кноте / knote6037@gmail.com`.

Если CLI пишет `Unauthorized: could not retrieve project` — значит токен отозван, нужен новый
(Netlify → User settings → Applications → Personal access tokens), и его надо положить в те же три места.

## API (Netlify Functions + Blobs)

Готовый скрипт:

```powershell
pwsh -File C:\KNOT\TOOLS\deploy-api.ps1 -Message "что поменял"
```

Он сам читает токен, деплоит и проверяет `/api/market`.
Вручную то же самое:

```powershell
$env:NETLIFY_AUTH_TOKEN = (Get-Content C:\KNOT\SITE\_tools\netlify\.token -Raw).Trim()
cd C:\KNOT\SITE
node C:\KNOT\TOOLS\netlify-cli\node_modules\netlify-cli\bin\run.js deploy --prod `
  --site f39e7bc4-2377-4d5e-a166-7656e05e2c68 --dir deploy --functions netlify/functions --message "текст"
```

`exit code: 1` в конце — норма, смотреть на строку `Deploy is live!`.
