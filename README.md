# DE Exchange

Онлайн-биржа внутри школьной «экономики»: аккаунты, кошелёк в USDT, крипта, NFT, дома и машины, соцсеть и боты, которые живут своей жизнью.

Сайт статикой на **surge.sh**, API — на **Netlify Functions + Netlify Blobs**.

- Живой сайт: https://de-exchange.surge.sh
- Демо: https://de-demo.surge.sh
- API: https://de-exchange.netlify.app

## Что лежит в репозитории

```
site/                  статический сайт целиком (index.html + assets)
netlify/functions/     API: аккаунты, состояние, биржа, NFT, соцсеть, боты
netlify.toml           конфиг Netlify: publish, functions, редиректы, расписания
package.json           зависимости функций (@netlify/blobs 8.2.0)
docs/                  ТЗ, деплой, описание рынка цен
tools/                 деплой-скрипт, тесты на puppeteer, сиды ботов, дашборд
```

## Как это работает

**Аккаунты и состояние.** Функция `api.js` принимает логин/регистрацию, хранит аккаунты и их состояние в Netlify Blobs (стор `de`). Пароль клиент хеширует сам (`deHash`, djb2-xor) и отправляет уже хеш — сервер хеш не проверяет повторно, а сравнивает с сохранённым. Хеш и есть учётные данные.

**Биржа.** `market-prices.js` — движок цен: 20-секундный тик, шум, возврат к среднему, влияние сделок, часовые корзины истории. Цены и история раздаются через `GET /api/market`. Клиент опрашивает их каждые 15 секунд и держит локальный снимок в `localStorage`, чтобы F5 не ронял график.

**Боты.** `bots-tick.js` раз в 20 минут, `bot-live.js` раз в минуту (расписания в `netlify.toml`). Мозги — `bot-brain.js`, имена — `bot-names.js`.

**NFT и соцсеть.** `nft-market.js`, `nft-content.js`, `social.js`.

## API

| Метод | Ручка | Что делает |
|---|---|---|
| GET | `/api/market` | цены, история, изменение за час |
| GET | `/api/market/prices` | только цены (лёгкий опрос) |
| POST | `/api/market/set` | ручная правка цены владельцем (`anchor` двигает базу) |
| POST | `/api/reg`, `/api/login` | аккаунты |
| GET/POST | `/api/state` | состояние аккаунта |
| POST | `/api/peek` | хеш пароля и кошелёк аккаунта (только владелец) |
| GET | `/api/bots/stats` | метрики ботов |
| POST | `/api/bots/seed`, `/tick`, `/boost`, `/decorate` | управление ботами |
| POST | `/api/bots/live` | публичный, мелкие действия ботов |

Права на админские ручки: ключ из переменной окружения `BOTS_KEY` **или** аккаунт владельца (ник + пароль).

## Переменные окружения (Netlify)

| Имя | Зачем |
|---|---|
| `BOTS_KEY` | ключ доступа к админским ручкам ботов и ручной правке цен |
| `NETLIFY_AUTH_TOKEN` | только для деплоя с машины, в коде не нужен |

Секретов в репозитории нет: ключи читаются из окружения. Токен деплоя лежит вне репозитория.

## Деплой

Сайт (статика):

```sh
cd site
surge . de-exchange.surge.sh
```

API:

```powershell
pwsh -File tools/deploy-api.ps1 -Message "что поменял"
```

Скрипт берёт токен из файла вне репозитория, деплоит `netlify/functions` и проверяет `/api/market`.

## Тесты и инструменты

`tools/` — puppeteer-скрипты, которые логинятся на живой сайт и проверяют сценарии: продажа не возвращает баланс, синк не теряет деньги, панель цен, вспышки графиков, NFT, профиль.

Для запуска нужен пароль тестового аккаунта в окружении:

```sh
DE_PASS=<пароль> node tools/de-sell-test.cjs
```

Прочие скрипты: `seed-bots.mjs` (создать ботов), `sim-bots.mjs` (прогнать торговлю), `serve.cjs` (локальный сервер), `shot.cjs` (скриншоты), `DE_dashboard.html` (админ-дашборд).

## Известные ограничения

- Хеш пароля — 32-битный djb2 без соли, перебирается. Хеш передаётся в запросах и фактически работает как пароль.
- Данные лежат в Netlify Blobs, без транзакций между функциями: гонки возможны и лечатся на клиенте.
- Боты — скрипты, а не ИИ: их «решения» детерминированы.
- NFT-картинки и часть ассетов — локальные файлы в `site/assets`.
