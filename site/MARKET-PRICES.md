# DE Exchange 2.6 — предлагаемые игровые цены

Валюта каталога — KNT. Базовая котировка симуляции 325 000 USDT/KNT, у каждого клиента она меняется при запуске и каждые 0,5 с. Стоимость имущества в USDT равна KNT × котировка. При прямой покупке добавляется комиссия 3%. Эквивалент и комиссию округляем до двух знаков, а списываем точную сумму из подтверждения. Обмен в банке берёт 0,35% из результата. Четыре контрольные цены сравниваем при одной базовой котировке.

Студия 1,2 KNT = 390 000 USDT (401 700 с комиссией). Базовый кейс 500 KNT = 162,5 млн USDT, то есть 416,67 студии. Источник разницы — несопоставимые исходные прайс-листы. Парк-авеню 140 KNT = 45,5 млн (46,865 млн с комиссией); Бавария 250 = 81,25/83,6875 млн, Луара 320 = 104/107,12 млн. Для 61 млн по Нью-Йорку необходим курс 435 714 без комиссии или 423 024 с комиссией. Для 101 млн по Баварии — 404 000 или 392 233, по Луаре — 315 625 или 306 432. Нет данных, из какой версии или котировки взяты 61/101 млн. В текущем локальном симуляторе при обычных тиках котировка колеблется вокруг базы. Комиссия 3% не объясняет разницу в сотни раз.

Модель оставляет уже согласованную лестницу недвижимости в KNT (1,2–320). Для повторяемых коллекционных покупок самая дешёвая модель без ауры стоит 1/400 студии; номиналы прошлых моделей делятся на 1 млн с сохранением порядка редкости. Обычные ауры ×1, ×1, ×1,25, ×1,75, ×2,5, ×4, ×6, ×8. Цены кейсов — округлённые математические ожидания нового дропа, делённые на 0,75. Это приблизительно 71–76% возврата при немедленной продаже, без изменения вероятностей платных кейсов. Вторичный NPC-рынок предлагает уже известный предмет за 115–165% его выкупной стоимости. Новые заявки продавца выставляются по выбранной им цене; бот исполняет их только до 115% оценки. Старые заявки сохраняют условия.

Премиальные уникальные номера — коллекционные трофеи. Прежняя шкала 2–30 млн KNT в пике превышала весь заявленный выпуск (17,5 млн). Новая шкала 20–300 ставит их между элитной квартирой и замком, сохраняя пропорции и порядок исходной редкости. У старых номеров сохраняется прежняя оценка, у новых хранится фактическая цена покупки.

Новые цены действуют при будущих операциях. После штатного обновления витрины действуют новые цены предложений NPC. Уже выставленные NFT-лоты игроков сохраняют условия. Старые NFT сохраняют оценку и выкуп, а апгрейд и крафт используют новые NFT. Крафт ограничивает выкупную стоимость результата суммарной стоимостью вложенных предметов. Ранее выданные подарочные коды сохраняют прежнюю шкалу. Для новых подарков и номеров используется код с версией, поэтому для их получения нужна версия 2.6.
